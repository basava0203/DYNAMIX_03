# Social Media Mental Health Sentiment Correlation Dashboard

## 📌 Overview
This project presents an interactive dashboard designed to explore and visualize correlations between social media usage and mental health sentiment across various demographic groups. The dashboard enables researchers and stakeholders to filter by age, gender, occupation, and social media engagement levels to uncover meaningful patterns.

## 📊 Dashboard Features
- **Demographic Filters:** Age (18–91), gender, occupation status, and average daily social media usage
- **Visualizations:**
  - Total respondents by gender
  - Social media impact score distribution
  - Respondent breakdown by occupation
  - Average age and engagement metrics
- **Interactive Elements:** Dynamic filtering and real-time chart updates

## 🧠 Purpose
To provide a data-driven tool for:
- Identifying trends between social media habits and mental well-being
- Supporting academic and clinical research
- Informing public health strategies and digital wellness initiatives

## 📁 Data
The dataset includes survey responses from **962 participants**, with attributes such as:
- Age
- Gender
- Occupation
- Self-reported social media impact score
- Time spent on social media platforms

## 🛠 Technologies Used
- **Frontend:** HTML, CSS, JavaScript (with charting libraries such as Chart.js or D3.js)
- **Backend:** (Optional) Python/Flask or Node.js for data serving
- **Data Processing:** Pandas, NumPy
- **Visualization:** Dashboard built using a framework like Dash, Streamlit, or Tableau

## 📈 Sample Insights
- Female respondents constituted the largest gender group in the survey.
- The average age of respondents was approximately 34 years.
- Social media impact scores varied widely across occupational groups.
